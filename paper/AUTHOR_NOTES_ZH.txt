论文定位与作者交接说明
====================

最终标题：Adaptive Memory Evolution: Controlling Stability-Plasticity in Agent Memory

这份稿件把研究问题组织为五个 RQ，而非复述实验批次。核心论点是：
在控制器权重、状态评分和环境流不变时，演化速率干预能够改变稳定知识保留与
适应速度的工作点。贡献不在 LNN，也不在证明所有记忆系统过去都没有动态更新。

最强证据：C1 在预设的 84 个速率配对中，27 对在两个端点上呈相反方向且通过
批次内 Holm 校正。该计数来自四个条件，共享样本的配对不是 27 次独立复现。
代表性结果：快速变化、容量 8 下，alpha=1 到 2 提升 adaptation score，
同时损失 stable retention。这支持可调节机制，不意味着单调或全局 Pareto 最优。

正文保留的重要边界：
1. B1-A 只支持“替换次数不足以解释收益”；没有完全消除替换对象、时机和寿命分布混杂。
2. 容量较大时固定策略可以胜出；B2 同时改变了噪声身份数量，不能写成纯容量 scaling law。
3. alpha=0 仍有离散更新和 T 的变化，不等于 frozen-state baseline。
4. 使用状态支撑保留，consistency 支撑旧版本抑制；组件实验不是正交因果分解。
5. 周期恢复与休眠知识保存不同；语义层可能让正确内容保留却仍返回旧答案。
6. 真实问答子集结果有限，单一 Agnes 后端及同模型评分不能支持普适 Agent 或 SOTA。
7. 状态维护增加工作量；记录容量不是整个系统严格的字节内存上限。

稿件目前覆盖：三项贡献、精确定义与方程、事件更新和因果顺序、局部状态性质的证明、
三个主表、工作区域与机制图、完整数值附录、统计与协议修正记录、参考文献及证据索引。
没有新增训练、重选参数或删除不利结果。
